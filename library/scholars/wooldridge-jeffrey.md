# 伍德里奇

**为什么值得学**：《计量经济学导论》以直觉讲解见长，是国内计量课的常用教材，也是本仓库计量术语的基准。

## 风格观察

待补。建议拆解《导论》讲"遗漏变量偏误"或"工具变量"的一节：先讲问题，再讲直觉，再给公式，最后给实例。这正是场景一希望 Claude 学会的讲解顺序。
