# 黄炜：经济学论文写作的三要领

**一句话**：论文要"细处求精益、宽处谋布局、高处争独到"，也就是细节经得起推敲、整体有一条主线、贡献改变了读者的理解。

## 要点

**三要领借自周其仁。**周其仁把企业突围的路径概括为"细处求精益、宽处谋布局、高处争独到"，黄炜把它用到论文上。讲座结尾概括成三句话："细而不碎、宽而不散、高而不虚"。

**AI 替代不了判断。**AI 可以润色语言、检查局部逻辑，但判断不了问题是否重要、证据是否撑得起结论、贡献是否成立。作者如果没有独立判断，流畅的文字反而会掩盖证据和结论之间的断裂。一个自测标准是：能不能在几分钟内讲清核心问题、识别方式、主要发现和意义。

**细处：论文站不站得住。**要反复问：概念准不准，边界清不清楚，方法和要回答的问题是否匹配，关键假设是否成立，证据链是否闭合，表达是否克制、前后一致。别人用过某种识别方法，不等于它在新的国家、制度和样本里仍然有效。方法名称只是起点，还要说清四件事：

- 比较对象是谁；
- 变异来自哪里；
- 读者需要接受哪些假设；
- 还有哪些替代解释排除不了。

每个判断都要受证据约束：没有直接测量的机制，不能写成确定结论；没有识别到的结果，要坦白说本文回答不了。

**宽处：全文的主线和组织。**黄炜用拍电影打比方：单个镜头拍得准是细处功夫，选哪些镜头、怎么排序是布局。研究中产生的大量结果不必都进正文。篇幅按内容对核心问题的重要性分配，不按投入时间分配。各部分的分工是：

| 部分 | 任务 |
| --- | --- |
| 导论 | 把问题立起来，不堆背景 |
| 文献综述 | 说明本文从哪里进入文献，不罗列前人成果 |
| 理论框架 | 帮读者理解关键机制和可检验的命题，不是展示推导 |
| 经验设计 | 说明本文凭什么能识别 |
| 结果 | 一层层兑现前文的承诺，再过渡到机制和更广的含义 |

标题、摘要和导论要兑现同一个承诺，不能各讲一套故事。

**高处：贡献值不值得记住。**别人没做过不等于有贡献。重要的问题来自三处：有普遍意义的经济现象或政策张力；文献长期讨论但没解释清楚的问题；具体事实背后可以迁移的一般机制。写法上是从事实到机制，再从机制到一般含义。显著的系数本身不是贡献；只有放进更大的学术对话，修正了既有认识、揭示了新约束或提供了新解释，才算贡献。

**三个修订案例**（纪要只有概述，没有论文题目）：

1. 小学学制由六年缩短为五年：区分能识别的结果和推不出的机制，既不拔高成宏大结论，也不写成狭窄的"五年与六年比较"。
2. 农村电商的性别效应：从描述数据集和若干劳动结果，聚焦到技术变迁如何改变女性劳动参与、家庭内部配置和代际人力资本；标题、摘要、导论和贡献随核心结果整体重写。
3. 生育政策、家庭结构与老年健康：初稿像"结果齐备的实验报告"，最后以"照护缺口"为核心机制把全文串起来。

**问答里的几点**：理论和实证要围绕同一个问题；不同章节引用文献的方式取决于该章节的功能；培养学术品味要理解经典研究为什么提这个问题、为什么这样切入，而不只模仿表面写法。

## 可以怎么用

- 场景二改稿时做三层检查：细（每个判断都有证据吗）、宽（每个结果都在为主线服务吗）、高（贡献改变了对什么的理解）。
- 写识别策略的段落时，用"比较对象、变异来源、需要接受的假设、排除不了的替代解释"四问组织。可以和 Cochrane 的识别清单（guide-cochrane-2005-writing-tips）合用。
- "标题、摘要、导论兑现同一个承诺"和《财经研究》的"摘要里的每个大词，正文都要接得住"（guide-cjyj-abstract-referee-comments）是同一条规则。
- 对 Claude 自己也是提醒：帮用户润色时，不能用流畅的文字掩盖证据不足。场景二的 skill 可以把"每个判断受证据约束"写成检查项。【判断】
