# Evans：顶刊发展经济学论文的引言结构

**一句话**：Evans 把一批顶刊发展经济学论文的引言逐段画了结构图，发现结果部分占的篇幅最多。

## 要点

归纳出的结构：

| 部分 | 段数 |
| --- | --- |
| 动机：一个困惑或问题 | 1–2 段 |
| 研究问题 | 1 段 |
| 实证方法 | — |
| 详细结果 | 3–4 段 |
| 相对文献的增量 | 多在引言靠后 |
| 路线图 | — |

- 顶刊引言通常 10–15 段（据转述）。
- Evans 另写了摘要篇（How To Write the Abstract of Your Development Economics Paper）：摘要有时只用一句动机，就进入研究问题和方法。
- 社交媒体讨论中，Arik Levinson 主张删掉路线图段。

## 可以怎么用

- 这个方法比结论更有用：**给范文引言逐段画结构图**。本仓库的范文拆解卡片（templates/paper.md）就是照这个做法设计的。
- 写引言时检查结果段的篇幅：如果结果只有一句话，就说明引言写成了"预告"。
