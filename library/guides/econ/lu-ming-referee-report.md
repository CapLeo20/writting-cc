# 陆铭：审稿要做到两个 C、两个 P

**一句话**：好的审稿意见要做到 constructive、professional、careful、polite。反过来读，作者能看出懂行的审稿人真正看重什么：亮点、文献、机制、制度背景，而不只是"内生性"三个字。

## 要点

**建设性（constructive）。**模型误设、度量误差、内生性这三条批评"基本不会错"。但如果审稿报告只谈这三条，说明审稿人对文章没有超出教科书的理解。作者更愿意告诉对方这些事：

- 研究里有一个作者自己没意识到的亮点；
- 遗漏了重要文献；
- 能找到某个数据来检验从 X 到 Y 的机制，甚至比较几种机制哪个更重要；
- 另一种故事更贴近真实的制度背景；
- 学术论文里不必讲那么多政策建议；
- 引言换个写法，工作会显得更重要、更有趣。

建议要做得到。例如不会要求用实验去改变收入差距，也不会要求用自然实验研究户籍，因为随机给农民工发户籍这件事从来没有发生过。

**方法与因果。**作者认为计量方法和因果识别在理论上没有直接对应。实验、工具变量（IV）、断点回归（RD）、倾向得分匹配（PSM）、双重差分（DID）都只是缓解遗漏变量和双向因果带来的偏误。用了之后，相关性更接近因果，但是不是因果还要看理论逻辑。只要研究策略保证了核心解释变量外生，OLS 就是好的估计。开创性研究常从相关性起步，价值在于提出了有创见的问题。

**一个例子。**一篇用截面 OLS 的稿件发现，在收入方程里"党员身份 × 教育"的交互项系数为负。作者没有要求换双胞胎数据，理由是：文献表明能力和教育互补；如果党员身份只代表能力，党员和教育就不该互相替代。所以只要系数符号可信，这个发现就能质疑"党员只代表能力"的说法。作者建议把这一点当成文章亮点来写。

**理论模型不是必需的。**两种情况下，实证文章不需要写数学模型：既有理论已经成熟，实证只看净效应多大、哪种机制成立；或者机制很直接，关心的是这个关系本身成不成立，例如同群效应（peer effect）。作者还指出，同一个相关关系既能写出 X 影响 Y 的模型，也能写出 Y 影响 X 的模型，所以数学模型本身确定不了因果方向。

**专业（professional）。**不接自己不熟悉领域的审稿。推荐一种技术之前，要知道它对这项研究是否适用、是否可行。原文："技术永远是手段，而不是目的本身。"（professional 一段）

**细心（careful）。**审稿人自己先别出错。作者举了两个常见错误：

- 说被解释变量（Y）的度量误差会导致衰减偏误。作者指出，衰减偏误只在解释变量（X）有度量误差时出现。
- 指责解释变量之间有共线性。没有共线性就用不着多元回归。为了让系数显著而删掉相关变量，会把它放进残差项，反而造成偏误。

**礼貌（polite）。**审稿报告不需要形容词，不用"愚蠢""幼稚"这类词。按期刊要求的时间审完。

## 可以怎么用

- **投稿前用审稿人视角自查**：亮点说出来了吗？能不能用数据比较几种机制？制度背景讲的故事是不是最贴近现实？政策建议是不是太多？引言有没有把工作的重要性和趣味讲出来？
- **回复审稿意见**：碰到"解释变量共线性""Y 的度量误差导致衰减偏误"这类意见时，可以用文中的道理礼貌地解释。
- **写识别策略**：可以借用作者的说法，方法让相关更接近因果，是否因果还要靠理论逻辑来论证。
- **写交互项结果**：系数方向可信时，可以像党员 × 教育的例子那样，把结果和理论争论接起来。

## 需要注意

- 关于 Y 的度量误差：严格说，经典度量误差（和真实值、解释变量都不相关）不会使 OLS 有偏，只会增大标准误；和解释变量相关的度量误差仍可能造成偏误。伍德里奇《计量经济学导论》讨论过这一点，具体章节待核。【判断】
- "截面 OLS 也可以很好"的前提是研究策略已经保证了外生性，不能当成不处理内生性的理由。
- 写作年份待核。近年中文期刊对识别的要求普遍更高，引用文中关于因果推断的看法时，注意当时的语境。【判断】
