# 五要素提纲法：用五项"填空"检验构思

**一句话**：动笔前先写出题目、摘要（500 字以内）、关键词、提纲（三级标题）和参考文献五项。写得出来，才说明问题和假说想清楚了。

## 要点

**五项分别检验四件事。**

| 要检验的 | 体现在哪一项 |
| --- | --- |
| 问题与假说 | 题目、摘要。问题和假说不清楚，题目和摘要就写不出来 |
| 思路与层次结构 | 提纲目录 |
| 核心概念 | 关键词 |
| 对已有研究的把握 | 参考文献 |

**这套格式也是评价标准。**写全了，导师才能逐项给出有针对性的意见。习惯笼统思考的学生，看不出自己哪里已经达标、哪里还欠缺。作者的指导方式是评价学生交上来的成果，不替学生想思路。

**摘要至少写两遍。**第一遍在构思阶段，凝练全文的目标、框架和思路；第二遍在正文写完后，按实际内容修改。原文："摘要至少应写两遍。"（正文谈摘要写法的一段）

**训练要有量，也要有多样性。**作者打了个比方：园子里不能只种辣椒。很多研究生迟迟入不了门，原因是训练量不足，尤其缺少不同类型的训练。

**附录给了一个示例。**题目是《农村"银保合作"创新模式：典型案例与理论含义》。摘要的顺序是：研究目的 → 新视角 → 分析框架（条件—机制—前提）→ 案例 → 两点发现 → 本文侧重。提纲五节：引言；已有研究评述与分析框架；案例分析；理论探讨；结论及政策含义。

## 可以怎么用

- 场景二开题或动笔前，让 Claude 按五项检查构思稿，逐项指出缺什么。重点看：只读题目和摘要，能不能说出本文的问题和假说。
- 这和聂辉华"先用一句经济学语言概括问题"（guide-nie-huihua-econ-paper）、Shapiro"先写理想引言"（guide-shapiro-2022-four-steps）是同一个思路。
- 第二遍摘要可以对照 guide-cjyj-abstract-referee-comments 的检查清单来改。

## 需要注意

- **作者署名是推断。**文中没有直接署名。依据有两条：作者自称指导研究生，并说示例最终形成了江如梦、刘西川的论文；刘西川署名的另一篇文章（guide-liu-xichuan-knowledge-increment）提到"我在'五要素'提纲法中"，而本文正好列了五项。
- 示例论文据文中说明发表为江如梦、刘西川《社－政支持型农村银保互联模式研究》，《金融理论与实践》2023 年第 2 期。期刊和期号未核实。
- 示例是案例研究，不是计量实证论文。提纲的层次可以借鉴，章节名不必照搬。
- 示例摘要的发现写得比较抽象（"有效实现信息共享、风险分担"），按《财经研究》的摘要标准还可以更具体。【判断】
