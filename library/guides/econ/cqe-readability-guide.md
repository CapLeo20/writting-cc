# 《经济学（季刊）》论文可读性改进建议

**一句话**：中文经济学顶刊少见的官方写作建议，要求题目反映结论、摘要讲发现、引言直入主题。

## 要点（据检索摘要，只看到前几条）

- **题目**：反映结论，避免"A 与 B"式的并列写法，可以写成"A 是否导致 B"；有主副标题时，主标题体现一般性的经济学问题。
- **摘要**：面向非专业读者，主要陈述研究发现；中文 200 字以内，英文 100 字以内。
- **关键词**：高度概括，覆盖面不宜过窄。
- **引言**：直入主题，讲清研究问题、意义、研究设计与数据、主要发现、对文献的贡献；文献综述多数情况下可以融入引言。据摘要，页面还提示不要直接写"边际贡献"字样。
- **数据分析**：正文不宜占用过多篇幅（细则未看到）。
- 投稿体例另规定全文尽量不超过 15,000 字。

## 可以怎么用

- 中文论文题目和摘要的直接依据。"主标题体现一般性经济学问题"可以作为中文论文叙事的总原则：中国情境是识别来源，问题本身要有一般性。
