# 陈强：经济学如何做实证研究及写作论文

**一句话**：实证研究从选题到投稿有一套固定步骤。写成论文时，引言相当于"扩展版摘要"；报告结果要同时讲统计显著性和经济显著性，并用稳健性检验回应"只报最好结果"的质疑。

## 要点

**论文是对新研究成果的汇报。**学生写不出论文，是因为要从学习已有知识转向创造新知识。

**研究的步骤**：准备（经济理论 + 计量方法和软件）→ 选题 → 探索性研究 → 收集整理数据 → 建立计量模型 → 选择计量方法 → 解释结果 → 诊断性检验 → 稳健性检验 → 写作 → 与同行交流 → 投稿。

**好的研究问题有四个标准。**

- 具体：在"X 对 Y 有何作用"里，X 和 Y 都明确。
- 有趣：回答"我们为什么要在乎"（Why should we care）。
- 新颖：有边际贡献，可以是新现象、新方法或新数据。
- 可行：找得到数据。

**有了想法再系统看文献。**一开始就大量读文献容易被淹没；先有想法，才知道该看什么，也更能带着批判的眼光看。探索性研究要回答两件事：别人做过没有（查 CNKI、JSTOR 等），数据能不能拿到。

**数据和模型的几条具体建议。**

- 拿到数据先看描述统计，按常识判断是否合理，例如虚拟变量的取值只能是 0 和 1。
- 注意统计口径，例如中国的"城镇登记失业率"和教科书里的失业率概念不同。
- 设定要合常识：人均变量配人均变量；FDI 起作用要时间，可以用期初 FDI 解释随后五年的增长，这样也能缓解双向因果。
- 遗漏变量几乎不可避免，论文里要讨论：遗漏变量和解释变量不相关时说明理由；相关时要处理（控制变量、代理变量、工具变量、面板数据等）。
- 用工具变量做两阶段最小二乘（2SLS）后，要做弱工具变量检验、过度识别检验和内生性检验，并从定性角度说明排他性约束为什么成立。

**解释结果分清两种显著性。**统计显著性看 p 值；经济显著性看系数大小和单位。例子是对数工资对教育年限回归，系数 0.0966，作者解读为多一年教育工资约高 9.66%。

**结果不如意，原因有三种**：计量方法不当、数据质量有问题、经济理论本身有问题。作者引林毅夫（2001）：理论推论和中国经验不一致时，正是发展理论的机会。

**数据挖掘有利有弊。**根据结果反复调整模型、只报告最好的结果，是一种数据挖掘。它能帮助发现设定错误，但用同一份数据检验由它启发的模型，检验就不客观。作者给的办法之一是做稳健性检验，不只报最好的结果。

**论文各部分怎么写。**

| 部分 | 作者的建议 |
| --- | --- |
| 标题 | 简洁、有吸引力，让读者知道本文做什么；写作中可以反复改 |
| 摘要 | 约 100 字，突出意义、方法和主要结论；正文完成后再写 |
| 引言 | 往往最后写。讲清问题和意义、数据、方法、主要结论、与文献的关系和边际贡献。有两种套路：传统套路先回顾文献再引出本文；现代套路先讲本文的方法和结论，再回到文献，后者越来越流行。最后一段通常给全文路标 |
| 文献回顾 | 短的并入引言，长的单列。目的是厘清本文与已有文献的关系，切忌堆砌。指出前人不足时语气要委婉，这些作者可能就是审稿人 |
| 背景或理论框架 | 讲一个完整的经济故事，熟悉现象的历史、制度和文化背景。例子是 Nunn and Qian（2011）用大量篇幅介绍土豆。理论模型不宜复杂到喧宾夺主 |
| 数据说明 | 详细到读者能按图索骥拿到同样的数据；说明处理步骤和潜在的质量问题 |
| 计量模型 | 说明为什么这个方法最合适，这是初学者最容易漏的 |
| 结论 | 回顾问题、方法、结论，可以重申贡献、指出局限和后续方向 |

可以引用的一句（引言一节）："引言将论文的精华部分以非技术性的方式呈现给读者，可视为扩展版的摘要。"

**写作伦理。**引用和抄袭的本质区别在于是否给出出处。间接引用、概述前人思想、对已有模型做小改动，也要注明来源。

## 需要注意

- 文中说 p 值大于 0.05 时"在统计上可将此系数视为零（不存在）"，说得太满。不显著只是不能拒绝系数为零，不等于效应不存在。论文里写"统计上不显著"，必要时报告置信区间。【判断】
- 对数工资系数 0.0966 读作 9.66% 是近似，精确的百分比变化是 exp(0.0966) − 1 ≈ 10.1%。系数小时差别不大，系数大时要换算。【判断】
- 文中把多重共线性列为要检验和调整的问题；陆铭（guide-lu-ming-referee-report）提醒，为了显著而删掉相关变量会带来遗漏变量偏误。合起来看：可以报告共线性，但不要靠删变量来解决。【判断】
- 作者建议文献回顾"一般按时间先后"。Cochrane 和 Head 更强调只讨论最相关的两三篇，并按它们和本文的关系组织。【判断】
