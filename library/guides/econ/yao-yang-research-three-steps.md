# 姚洋：论文发表"三步曲"——选题、技巧、写作

**一句话**：选题以问题为导向，从中国现实里找现有理论解释不了的现象；做研究时先用自然语言讲通故事再写模型，实证要不断排除替代解释；写作时在前言里讲清文献定位、故事、方法、数据和结论。

## 要点

### 选题

**比较优势在中国实践。**讲者认为中国学者在纯理论上很难和美国同行竞争，比较优势在于从中国的变化里提出问题。

**编辑先看前言和摘要。**讲者所编的期刊每年收七八百篇稿件，约三分之二由主编直接拒掉，很多只看了前言和摘要就能判断；送审的再拒一半。

**好选题有四类。**

| 类型 | 讲者的例子 |
| --- | --- |
| 现实中有现象现有理论解释不了，于是发展新理论 | 腐败通常不利于增长，为什么在中国没有阻碍增长 |
| 解释一个谜或一个意外 | 国内投资回报高，却持有大量外汇储备、输出资本；法治不健全，企业为什么还签合同 |
| 用新数据或新方法检验现有理论 | 讲者说，用微观数据的稿件在他手上的成功率约 60%–70% |
| 应用微观：用微观理论解释现象，再用数据证明，最好写一个小模型 | 新农合是否降低农村居民信教的概率 |

讲者转述科斯研究所 Lee Benham 的要求：先要有一个让人"喔，没想到"的发现，再给一个让人"啊哈"的看似合理的解释。

**不好的选题也有四类。**

- 改别人模型的假设，推出一个平凡的结论。成熟模型的假设已经磨到最简，改了往往出错。
- 生搬硬套现成理论，没先把事实搞清楚。例子是用科斯产权理论硬套中国历代土地制度。
- "稻草理论"：把一个不重要的因素无限放大。
- 研究"决定因素"，例如工资由哪些因素决定。变量永远放不全；应该研究一个机制，控制其他变量把它讲清楚，例如工会对工资有没有影响。

### 技巧

**理论：先有故事，再写模型。**先用自然语言讲一个符合直觉的故事。讲不出来，说明哪里有问题。先知道要什么结论，再找能推出它的最小假设集合；讲者以阿罗不可能定理为例。最好用现成的、恰当的经济学模型来讲，例子是 Acemoglu 用"承诺问题"解释西方选举权的扩大。

**为什么还要数学。**自然语言有漏洞，写成模型才会发现没想清楚的地方，比如"国内回报高却输出资本"，口头上好讲，写成模型并不容易。

**判断理论模型好坏的几条标准：**

- 假设是否合理，有没有"短路"，即一个假设驱动了全部结论；
- 用的模型是否恰当，逻辑是否清楚；
- 模型是否精巧；
- 结论是否符合直觉；
- 能否推出一般化的结论；
- 能否经得起数据检验（讲者认为这一条要求偏高）。

**实证：数据、故事、替代解释。**

- 好数据第一。少用被用滥的省级数据，花功夫收集县级、城市级数据。
- 实证也要讲故事。最好有理论框架，用它决定哪些是解释变量、哪些是控制变量。
- 从多个方面验证。数据支持某个理论，不代表理论就对，因为其他理论也可能产生同样的数据，所以要不断问有没有替代解释。
- 做"反面"检验：村庄选举应该让村干部多修桥、多建灌溉，但不应该影响孩子上中学；如果后者也有影响，数据可能有问题。
- 内生性要逐项想清：伪相关；时间趋势（省级数据可加省份虚拟变量乘以日历时间）；遗漏变量；反向因果（想长期投资的租户才去签长期租约）。
- 永远想象对面坐着一位审稿人，用计量结果回答他可能提的每个问题。

### 写作

- 找范文"依葫芦画瓢"。讲者说林毅夫 1987 年回国时就是这样做的。
- 开篇说清文献定位。Lee Benham 要求摘要的头二十个字（英文是头二十个词）就让人知道文章要说什么。
- 审稿人一般先看前言，再看结论。前言里要讲清：文献定位和贡献、故事、方法、主要结论、数据来源。和正文重复不要紧。
- 直面假设和数据的局限，承认它们，并认真为自己辩护。没有干净的数据，审稿人也不期待。
- 写给读者看，不写给自己。理论文章的第一稿要一步一步写，不跳步。
- 守规范：短句；不能有错别字，至少通读两遍；正文引用和参考文献一一对应；引用体例和图表按刊物要求做。

### 三个研究实例

1. **中性政府**（与贺大兴，发表于《经济研究》）：从"赶超国家社会平等、政府强有力"两个观察出发，解释平等如何通过政府行为促进增长，并和 Esteban 与 Ray 在 AER 上关于游说和资源错配的文章对话。
2. **基础设施投资与居民消费**（与陈斌开）：省级面板，基准结果是基础设施投资占比上升 1 个百分点，居民消费占 GDP 的比重下降 2.8 个百分点。之后依次做了滞后一年和三年、五年平均、省份时间趋势、换控制变量、私人投资的反面检验、动态面板 GMM、结构式递归方程（SUR 和 3SLS）。讲者承认仍有内生性问题，并以此说明为什么鼓励用微观数据。
3. **市场化与党的精英化**（当时在写）：从 Nee（1989）的预测和中国事实不符出发，写一个简单模型，为实证铺路。讲者说，写模型时才发现之前有些地方没想清楚。

### 总结

经济学的目标是解释世界，不是预测；经验研究要有理论贡献；关键是在不同理论之间、理论和经验之间建立联想。可以引用的一句（第三部分）："坚持片面而深刻，拒绝广博而肤浅。"

## 可以怎么用

- **选题检查表**：四类好选题、四类坏选题可以直接用。"××的影响因素研究"要改成"某一个机制"的问题。
- **组织稳健性部分**：按"审稿人会问什么"来排，包括反面检验（安慰剂结果）。这和刘西川"实证分析是排除法"（guide-liu-xichuan-empirical-writing-eight-lectures）、黄炜的"替代解释"（guide-huang-wei-2026-three-essentials）是同一个思路。
- **前言检查项**：文献定位、故事、方法、结论、数据来源，五项都在前言里出现了吗？和 Cochrane、Head 的要求互相印证；"数据来源写进前言"是本文特别强调的一条。
- **理论部分**：写模型前先用两三句自然语言写出故事和结论，交给 Claude 检查能否讲通。

## 需要注意

- 这是讲座文字稿，口语化，有明显的转写错误。例如"ORG 模型（Organization Generation）"应是世代交叠（OLG）模型；Acemgolu、Commetment、Emprical IO 是拼写错误。【判断】
- 讲者说 Acemoglu 的承诺故事"也是 Edward Prescott 得诺贝尔奖的模型"，大概是指 Kydland 和 Prescott 关于承诺和时间不一致的研究，原话不精确。【判断】
- 讲座大约在 2010 年前后。推断依据有三条："十年之后中国 GDP 总量超过美国""从 2020 年开始再等 50 年"，以及 CHARLS 当时只做了甘肃、浙江两轮。所以关于数据可得性的说法已经过时：CHARLS、CFPS 早已公开，可用的微观数据也远不止 CHIPs 和 CHNS。【判断】
- 基础设施的例子里，解释变量先说是"占省政府支出的比例"，报告结果时又说"占 GDP 的比重"，前后不一，以论文原文为准。
- "先有结论再写模型"说的是理论建模的思路。实证研究里先定结论、再调设定直到结果好看，正是刘西川批评的做法，两者不要混淆。【判断】
- "微观数据稿件成功率 60%–70%"是讲者对当时所编期刊的个人印象。讲者自称"发过 AER、APSR"，本卡没有核实。
