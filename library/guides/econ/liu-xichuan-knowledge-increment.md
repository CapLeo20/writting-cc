# 刘西川：以知识增量为目标写学位论文

**一句话**：论文的每一部分都服务于"提出问题—提出假说—验证假说—理论对话"这条证伪链条。目标是给已有知识增加东西，而不是走完"找数据—跑回归—写结果"的流程。

## 要点

**知识的形态是问题与假说。**作者借用波普尔的知识增长图式 P1→TT→EE→P2（旧问题 → 试探性理论 → 排除错误 → 新问题）。所谓"问题"，本质上是对既有研究或既有认识的不满，所以问题总是指向既有研究的局限。

**"二维四象限"给选题定位。**纵轴是理论新旧，横轴是经验新旧：

| 类型 | 作者的命名 | 作者的评价 |
| --- | --- | --- |
| 旧理论 + 旧经验 | 常识确认 | 通常没有知识增量 |
| 旧理论 + 新经验 | 跟踪填补 | 有描述价值，理论贡献有限 |
| 新理论 + 新经验 | 原创突破 | 最有奠基性，难度最大 |
| 新理论 + 旧经验 | 范式转换 | 对老问题提出更有解释力的新理论；作者认为这是研究生最可操作的路径 |

**八个部分各有任务。**作者按学位论文的标准结构逐一说明：

| 部分 | 要完成的任务 | 作者点名的常见毛病 |
| --- | --- | --- |
| 前言 | 依次讲清问题（Problem，现实困境）、疑问（Question，既有研究答不了的科学问题，分描述性、因果性、机制性三类）、目的、假说 | 写成"×××对×××的影响研究"，连疑问都算不上 |
| 文献综述 | 回答三问：旧理论解释了什么；边界在哪里；填补这个缺口为什么重要 | 只述不评；综述和本文的问题脱节 |
| 理论分析 | 构建假说。要有"元问题框架"（理性还是有限理性、信息不对称还是制度约束等）；假说要比旧理论更高明；要有经验基础和经验质感 | 把几篇文献的结论"拼装"成假说；堆砌学术黑话 |
| 研究设计与方法 | 问题决定设计，设计决定方法；数据只是约束，不是起点。判断标准：这个设计能不能证伪假说 | 方法先行；数据先行；跑出什么就接受什么，调设定直到结果好看 |
| 研究结果 | 把数据变成证据：每个结果都要接到疑问和假说上。实证分析的手段是"在控制基础上的比较" | 表格、图和客观描述的机械组合 |
| 分析与讨论 | 和前人研究对话：用图尔敏论证模型组织（结果是数据，新假说是断言，文献是保证和支撑）；说清新假说的适用边界 | 只讲自己的结果，不引前人 |
| 研究结论 | 从结果提炼出观点，正面回答前面提出的问题 | 把结论写成结果的精简版，例如只写"X 对 Y 有显著正向影响" |
| 结语 | 总结旧问题怎么解决的，提出新问题 | — |

**五点提醒**（文末）：现象是研究的起点；问题呈现的是既有认识的局限；假说来自理论分析，不是拼装文献；实证分析是有控制的比较；理论对话要找准一个具体的旧理论作为挑战对象。

可以引用的一句（结语第 3 段）："哪一个环节脱了钩，知识增量就会在那里漏掉。"

## 可以怎么用

- 场景二动笔前或改稿时，按上面的表逐部分问一句：这一部分和假说是什么关系？答不上来的部分就是要改的地方。
- 文献综述的三问可以直接当段落骨架：已解释什么 → 边界在哪 → 为什么值得填。它和 Head 引言公式的"前作 → 增量"（guide-head-introduction-formula）是同一件事。
- 检查结论节：结论句要回答引言里的疑问，不复述系数。量级放在结果节报告，见 pattern-reporting-magnitude。
- 四象限可以用来回答"我的增量属于哪一格"，写贡献段之前先想清楚。

## 需要注意

- 文章针对学位论文。期刊论文篇幅短，"分析与讨论""研究结论""结语"常合并成一节。中文期刊的常见结构见 pattern-intro-structures。
- 作者认为机制性问题"可能需要定性研究或混合研究设计"。经济学期刊里的机制分析多用定量方法，写法可参考江艇（2022）（尚未收录）。【判断】
- 四象限的表述前后不完全一致：表格里推荐的是"新理论 + 旧经验"，结语又说知识增长发生在"新经验与旧理论的张力之中"。可以这样理解：新经验暴露旧理论的边界，再由新理论来回应。【判断】
- 以假说检验为主线的写法适合"提出假说 → 检验"的实证论文。纯描述性的论文，比如指标测度类，用起来要变通。【判断】
- "二维四象限""五要素提纲法"是作者自己的框架，不是学界通用术语，引用时注明出处。
