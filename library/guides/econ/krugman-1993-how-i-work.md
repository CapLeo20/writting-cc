# Krugman《我如何工作》

**一句话**：用最简单的模型讲清一个想法；模型是隐喻，不是对现实的描述。

## 要点

发表于《American Economist》（1993），四条研究规则：

1. **听"外邦人"的话**：留意领域外聪明人在说什么，哪怕他们不用你的分析语言。
2. **质疑问题本身**：领域卡住时，可能是问题问错了；相邻的问题往往更容易、也更有意思。
3. **敢于"犯傻"**：不要只在熟悉的假设上榨取最后一点结论；新假设能带来洞见，就不必在意它看起来奇怪。
4. **简化**：用能承载想法的最简单模型。精简到骨架，能逼你找到论证的核心，也会暴露你其实没话可说的地方。

Krugman 把模型比作"思想的投矛器"，也承认这样做的代价：同行可能以为用小模型表达的洞见一定很浅。

## 可以怎么用

- 理论部分、研究假说部分的写作原则：先用最简单的版本讲清机制，再加复杂性。
- 对"故事性"的启发：简单模型本身就是一个可以讲出来的故事。
