# 《财经研究》：从审稿意见看摘要怎么写

**一句话**：摘要按"背景 → 问题 → 方法与数据 → 发现 → 政策含义"写，每部分一两句。结论要具体到方向和数值，不引文献，不写研究现状，不给自己贴金。

## 要点

**基本结构是五段式。**审稿人的具体建议是：不要把背景、方法、结果、机制、拓展、政策建议全塞进去，分几个层次，每部分 1–2 句，突出贡献和创新。一位作者的改法是删掉文献引用，按五个要素重排，统一核心术语。改完的摘要"不依赖正文"也能看懂。

**审稿意见里常见的七类问题。**

| 类别 | 问题 | 审稿意见的要点 |
| --- | --- | --- |
| 内容 | 写成文献综述 | 摘要里不引文献，也不写研究现状 |
| 内容 | 结论含糊 | 只说"产生分化"不行，要说清产生了什么分化 |
| 内容 | 自我评价 | 删掉"系统揭示""丰富和深化"这类没有对应具体内容的说法，只留结论和方法 |
| 内容 | 机制空泛 | "外部压力机制和内部治理机制"太宽；作者改成"增加媒体报道、投资者实地调研"和"增加绿色投资、改善绿色绩效" |
| 内容 | 概念外推 | 实证只测了"异地新设企业"，标题和摘要就不要泛称"资本跨地区流动"；宣称的研究视角在正文里要落实 |
| 形式 | 冗长 | 方法、数据和结论全放在一起，要精炼 |
| 形式 | 要素残缺、列举细例 | 缺了必要要素就要重写；不必在摘要里举具体平台的例子 |

原文对概念外推的概括："摘要里的每个大词，正文都要接得住。"（第二节第 5 条）

**加分项是写关键数值。**一篇论文按审稿意见在摘要里写入核心效应（综合赋权指数提高 0.026 个标准差）和样本信息（26 个国家、2000—2024 年、37 万余名女性）。

**开头不要只写"鲜有学者关注……"。**审稿人认为这种开头不足以说明问题重要，应该把读者引向空白背后的现实关切。

**文中给的模板顺序**：背景与意义 → 研究对象、数据和方法 → 核心结论（可带数值）→ 机制（具体到场景的传导渠道）→ 异质性与拓展 → 理论贡献和政策含义。

## 可以怎么用

- 场景二写中文摘要时，用上面七类问题逐条检查。
- 摘要里放一个核心效应值，并给出参照，和 pattern-reporting-magnitude 的做法一致。
- "机制写到具体渠道""概念不要外推"两条同样适用于标题和引言。
- 和《经济学（季刊）》的建议（guide-cqe-readability-guide）对照：两刊都要求摘要以发现为主。季刊据检索摘要限 200 字以内，本文没有给字数。

## 需要注意

- 这是期刊公众号根据审稿意见整理的文章，不是正式的投稿须知。字数等硬要求以官网投稿须知为准（待核实）。
- "五段式"和文末模板不完全一致：模板多了机制和异质性，而审稿人又批评过什么都往里塞。可以理解为：五段是骨架，机制和异质性按字数取舍。【判断】
- 文中提到两篇按这个结构修改摘要的稿件。2026-11-12 检索确认都已在本刊发表：解子恒、何祺、张振堃《"闭门造车"还是"同舟共济"：知识产权保护与创新知识流动》（2026 年第 7 期）；谢杰、刘艳平《制度型开放"双试点"政策缩小收入差距的协同效应研究》（2026 年第 2 期）。依据是上财期刊社网站的检索摘要，详见 journal-cjyj。
