# 皮建才：经济学论文写作"五部曲"

**一句话**：写论文分五步：定位、选题、构架、成文、修改。作者分别比作打靶子、找座位、选兵器、加调料、补漏子。

## 要点

| 步骤 | 比喻 | 作者的意思 |
| --- | --- | --- |
| 定位 | 打靶子 | 瞄准最高级别的期刊（国内《经济研究》、国际 AER）。打不中，也可能落在一般的 CSSCI 或 SSCI 期刊。作者认为定位就是"品味"问题，引张五常为例 |
| 选题 | 找座位 | 标准有两条：题目本身是否重要；有没有被别人做过。作者引张五常：先找到选题、想好思路，再去检索文献，选题不是从文献堆里找出来的 |
| 构架 | 选兵器 | 分析工具要和问题匹配。简单工具对付复杂问题会力不从心，复杂工具对付简单问题是大材小用 |
| 成文 | 加调料 | 论文要视角独特、论证透彻，还要可读。不能只堆公式，也不能只给一个答案。主编和读者不一定懂你那个方向的数学，文字不清楚就可能被直接拒稿（desk rejection） |
| 修改 | 补漏子 | 编辑初审发现大漏洞会直接拒稿。几乎所有论文都要改一轮以上，会改论文才算会写论文 |

五步是一个整体。作者以林毅夫的经历说明：论证清楚透彻对应第二到四步，敢于挑战权威的勇气背后是第一步讲的品味，所以把定位放在第一步。

可以引用的一句（成文一段）："经济学论文要求的是视角独特，论证透彻。"

## 可以怎么用

- 选题自查两问：重要吗？有人做过吗？这两问分别对应 Head 引言公式里的 Hook 和 Value-added（guide-head-introduction-formula）。
- "先有想法和思路，再系统看文献"这一条，陈强（guide-chen-qiang-2015-empirical-research）和刘西川（guide-liu-xichuan-knowledge-increment，"现象是研究的起点"）也这样主张，可以合起来作为选题阶段的建议。
- "成文"一步讲的是原则。具体写法看 Cochrane、Head 等卡片。

## 需要注意

- 定位一步讲的是投稿策略和学术品味，不是写作技巧。作者没有讨论"瞄准顶刊"会拉长发表周期的代价。【判断】
- 全文比喻多，可操作的细节少。适合作为总框架，不适合当检查清单。【判断】
- 先选题、后看文献，可能做了很久才发现别人已经做过。陈强的做法是有了想法后先做一轮"探索性"文献检索，再决定做不做。【判断】
