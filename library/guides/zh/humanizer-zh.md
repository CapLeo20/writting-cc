# Humanizer-zh：中文去模板化规则

**一句话**：31 种中文模板化表达的识别与改写规则，最重要的是它的优先级——先保住信息和确定程度，再改表达。

## 要点（2026-09-23 修订版）

**优先级**（约束冲突时依次处理）：

1. 保留信息和确定程度：不增加事实，不丢独立信息；不把相关改成因果、可能改成确定、计划改成完成。
2. 遵守用户的编辑范围和文体。
3. 匹配作者声音。
4. 最后才处理具体表达问题。模式清单是检查线索，不是禁词表。

**31 种模式，分六组**：铺垫代替陈述（不是 X 而是 Y、单句收尾、格言式伪深度、起跑式铺垫、与假想敌辩论）；公式化节奏（强凑三段式、句式开头复读、破折号滥用、限定词堆叠、生造复合词、被动与缺主语）；拔高与借权威（AI 高频词、意义拔高、模糊关联、句尾拔高、宣传语、借权威、回避"是/有"）；公式化排版（粗体装饰、装饰性标题、标点）；聊天与草稿残留（客服腔、知识边界免责、首句复读标题、谈论上一稿）；中文补充检查（层叠的"的"、"进行＋动词"、被字句堆叠、四字词排比、"随着……的发展"开头、套话收尾）。

它明确说：学术文本里被动句、四字格和名词化表达可以符合文体，不强行口语化。

## 可以怎么用

- 场景一、二的"反面模式"主要来源，见 anti-pattern-ai-tells-zh。
- 它的优先级排序应该原样保留到本仓库的所有改写规则里。
