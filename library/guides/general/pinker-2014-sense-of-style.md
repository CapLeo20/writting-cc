# Pinker《风格感觉》

**一句话**：坏文章最主要的原因是"知识的诅咒"——作者忘了读者不知道自己知道的东西。

## 要点

- **知识的诅咒**：懂得越多，越难写清楚。Pinker 称这是"好人写出坏文章"的最佳解释。
- 光靠"体谅读者"不够，因为人很不擅长猜别人知道什么。办法是把草稿拿给有代表性的读者测试。
- **经典风格**：像指给读者看一样写，具体、可视、像对话；少用 somewhat、relatively、apparently 这类含糊限定。

## 可以怎么用

- 三个场景都适用：场景一 Claude 给你讲论文；场景二你写给审稿人；场景三 agent 写给另一个没有上下文的 agent。
- "拿给有代表性的读者测试"可以交给一个没有上下文的子 agent 做（Anthropic 的 doc-coauthoring skill 就有 Reader Testing 这一步）。
