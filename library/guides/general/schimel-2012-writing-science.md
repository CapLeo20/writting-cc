# Schimel《Writing Science》

**一句话**：科学论文要讲故事，结构是 OCAR：开场、挑战、行动、解决。

## 要点

- **O**pening：开场，交代背景和读者关心的大问题。
- **C**hallenge：挑战，指出未解决的具体问题（张力所在）。
- **A**ction：行动，本文怎么做。
- **R**esolution：解决，得到什么答案、意味着什么。
- 书里专门有一章讲"漏斗"：怎样从开场的大问题收窄到具体挑战。
- 论文通常用 OCAR；基金申请书更"前置"，像新闻写法。

作者是 UC Santa Barbara 土壤与生态系统生态学教授。这本书是理工科背景读者也熟悉的写作书，适合作为从理工科转到经济学写作的桥梁。

## 可以怎么用

- 和 Keith Head 的引言五步法对照：Hook ≈ O，Antecedents 指出的不足 ≈ C，Question 和 Value-added ≈ A 和 R。
- 见 pattern-narrative-skeletons。
