# 摘要怎么写

**一句话**：摘要只讲本文发现了什么，具体到方向和数值。用几句话依次交代背景、问题、方法与数据、发现和含义。构思时先写一稿逼自己想清楚，正文写完再按实际结果重写。

## 做法

### 1. 内容：只讲本文的发现

各份指南在这一点上没有分歧：

- 写发现了什么，不写打算做什么、做了哪些工作。依据：Cochrane；《经济学（季刊）》"主要陈述研究发现"。
- 结论要具体，说清方向和对象，不能只说"有影响"。依据：Cochrane 的反例；《财经研究》审稿意见"要说清产生了什么分化"。
- 放一个核心数值，并给出参照。依据：《财经研究》的"加分项"；写法见 pattern-reporting-magnitude。
- 机制写到具体渠道，不用"外部压力机制"这类大词。依据：《财经研究》。
- 不引文献，不写研究现状。依据：Cochrane；《财经研究》。
- 不给自己贴金，不用"系统揭示""丰富和深化"这类说法。依据：《财经研究》；Cochrane"不要用形容词描述自己的工作"。
- 摘要里的概念要和正文的测度对得上。依据：《财经研究》"每个大词，正文都要接得住"；黄炜"标题、摘要、导论兑现同一个承诺"。

### 2. 顺序：几个固定的位置

| 来源 | 摘要的顺序 |
| --- | --- |
| 《财经研究》公众号 | 背景 → 问题 → 方法与数据 → 发现 → 政策含义；文末模板另有机制和异质性 |
| 《经济研究》英文梗概（2017 年起） | 背景与意义 → 主题与思路 → 方法、理论、数据来源 → 主要结论及政策建议 → 创新与贡献 |
| 陈强 | 意义 → 方法 → 主要结论 |
| Evans（英文发展经济学） | 有时只用一句动机，就进入研究问题和方法 |

几种顺序合起来看：背景最多一句；研究问题紧跟其后，姚洋转述的标准是"头二十个字"就让人知道文章要说什么；发现占的篇幅最多。【判断】

第一句直接写现实关切或研究问题。不要写"鲜有学者关注……"（《财经研究》），也不要写"随着……的发展"（anti-pattern-ai-tells-zh）。

### 3. 篇幅：按目标刊

| 来源 | 字数 |
| --- | --- |
| Cochrane（英文期刊） | 100–150 词。注意是英文词数，不是汉字数 |
| 《经济学（季刊）》 | 中文 200 字以内（据检索摘要） |
| 《经济学动态》 | 约 200 字（转引） |
| 陈强 | 约 100 字 |
| 刘西川的五要素提纲 | 500 字以内。这是构思稿的训练要求，不是投稿标准 |
| 《财经研究》《数量经济技术经济研究》、IREF、EAP | 待核实，以投稿须知为准 |

### 4. 写两遍

- 构思阶段写第一遍，逼自己想清楚什么最重要。依据：刘西川"摘要至少写两遍"；Jacobsen 从摘要和引言写起；Shapiro 先写"理想引言"。
- 正文写完后按实际结果重写。依据：刘西川；陈强"摘要通常在论文主体完成后才撰写"。

两种说法不矛盾：第一稿是思考工具，定稿以结果为准。【判断】

### 5. 检查清单

1. 只读第一句，能知道本文研究什么吗？
2. 有没有一个具体的发现，包括方向和数值？
3. 机制写的是具体渠道吗？
4. 有没有引文献、写研究现状？
5. 有没有"系统揭示""丰富了""首次"这类自我评价？
6. 摘要里的概念，正文的测度接得住吗？
7. 字数符合目标刊吗？
8. 有没有错别字？姚洋提醒，摘要里有错别字就可能被拒。

## 例子

**虚构示例**（主题和数字都是占位）：

> 改前：本文基于……数据，运用双重差分方法，系统研究了 X 对 Y 的影响，发现 X 显著影响了 Y，丰富和深化了相关研究。
>
> 改后：[一句背景]。本文利用 [某政策] 在 [地区] 分批推开的时间差，研究 X 对 Y 的影响。X 使 Y 提高 [数值]，约为样本均值的 [比例]；效果主要来自 [具体渠道]，集中在 [某类对象]。这意味着 [含义]。

改前的问题：没有具体发现，没有数值，有自我评价。改后按"背景 → 识别 → 发现与数值 → 渠道 → 含义"写。

**真实论文**：《财经研究》公众号拿谢杰、刘艳平（2026，《财经研究》第 2 期）的摘要作示范，说它按"背景 → 视角 → 对象 → 数据方法 → 发现 → 机制 → 异质性 → 协同结论 → 建议"写。本仓库只看过检索摘要，还没读原文。

## 适用边界

- 中文期刊（《财经研究》、《经济研究》英文梗概）常要求写政策含义；本仓库收的英文指南很少这样要求。【判断】
- 理论论文的摘要没有"数据与方法"，换成"模型设定和主要命题"。【判断】
- 字数和必备要素以目标刊当年的投稿须知为准。
