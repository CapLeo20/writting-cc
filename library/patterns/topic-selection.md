# 选题

**一句话**：好题目从现象出发，指向现有理论或文献说不清的地方。动手之前，用一句话、一份五要素提纲或一篇"理想引言"检验它，再查文献和数据，确认它新、可行。

## 做法

### 1. 问题从现象来，不从文献堆或方法来

几位作者说法不同，方向一致：

- 刘西川：现象是研究的起点；问题的本质是对既有认识的不满。
- 姚洋：中国学者的比较优势在中国的实践，要坚持问题导向。
- 皮建才转述张五常：选题在读文献之前，不是从文献堆里找出来的。
- 黄炜：好研究以问题为出发点，不是拿着现成工具找应用对象。
- 刘西川还反对"方法先行"和"数据先行"。

陈强的说法更宽：问题可以来自理论、对现象的观察、政策，也可以是对已有文献的改进；没有想法时，先浏览顶刊。Krugman 补充了两条：听听领域外的聪明人在说什么；领域卡住时，质疑问题本身。

### 2. 好问题的几种类型

| 类型 | 来源里的说法 | 对应 |
| --- | --- | --- |
| 现有理论解释不了的现象 | 姚洋第一类；刘西川"新理论 + 旧经验" | 叙事上的困惑型（pattern-narrative-skeletons） |
| 谜或意外 | 姚洋转述 Lee Benham：先让人"喔"，再让人"啊哈" | Head 的"Y 令人困惑" |
| 用新数据或新方法检验已有理论 | 姚洋第三类；陈强"新现象、新方法、新数据" | — |
| 全新的现象或政策 | 陈强的例子：家庭联产承包责任制、沪港通 | 刘西川认为"旧理论 + 新经验"的理论贡献有限 |
| 从具体情境提炼一般机制 | 黄炜"高处争独到"：从事实到机制，再到一般含义 | 《经济学（季刊）》：主标题体现一般性问题 |

### 3. 要避开的题目

- 改别人模型的假设，推出一个平凡的结论（姚洋）。
- 生搬硬套现成理论，没先把事实搞清楚（姚洋）。
- "稻草理论"：把一个不重要的因素无限放大（姚洋）。
- "××的影响因素研究"：变量永远放不全，应该研究一个机制（姚洋；见 anti-pattern-ai-tells-zh）。
- "×××对×××的影响研究"这种标题式陈述，连疑问都算不上（刘西川）。
- 用成熟理论解释已知现象的"常识确认"（刘西川）。
- 唯一的动机是"大家都在做"（Head）。
- 只因为"别人没做过"。黄炜提醒，这不自动等于贡献。
- 对新手来说，已被做烂或过于困难的题目（陈强），以及被用滥的数据（姚洋举的例子是省级数据）。

### 4. 动手前的检验

1. **一句话**：用经济学语言把问题写成一句话（聂辉华），形式上能写成"X 对 Y 有何作用"或"为什么会出现 Y"（陈强）。
2. **四个标准**：具体、有趣、新颖、可行（陈强）。皮建才压缩成两条：重要吗？有人做过吗？
3. **五要素提纲**：写出题目、摘要、关键词、三级提纲和参考文献，看问题和假说能不能从题目和摘要里读出来（刘西川）。
4. **理想引言**：假设结果如愿，引言能写得让自己满意吗？满意才值得做（Shapiro）。
5. **探索性检索**：查 CNKI、JSTOR 等，确认没被做过，也确认数据拿得到（陈强）。
6. **几分钟讲清**：能不能用几分钟讲清问题、识别、发现和意义（黄炜）。还没有结果时，用假想的结果试讲。
7. **想象审稿人**：除了"模型误设、度量误差、内生性"这三条，审稿人还会提出什么更实质的问题（陆铭；姚洋"永远想象对面坐着审稿人"）？

### 5. 场景二里 Claude 怎么用这张卡片

## 例子

- 谜（讲座里的例子，没有成文）：国内投资回报高，中国却持有大量外汇储备、输出资本；法治不健全，企业为什么还签合同。来源：guide-yao-yang-research-three-steps。
- 全新的现象：Lin（1992，AER）研究家庭联产承包责任制对农业增长的影响。来源：guide-chen-qiang-2015-empirical-research，期刊信息按陈强文末参考文献。
- 假说示意：理性选择理论解释不了农产品"惜售"，于是提出"风险规避异质性"假说。这是刘西川举的示意例子，不是真实论文。来源：guide-liu-xichuan-knowledge-increment。

## 适用边界

- 来源大多针对实证论文，尤其是应用微观。纯理论选题另看 Krugman 和 Varian（Varian 卡片待补）。
- "从中国实践找问题"是中国学者投中文期刊的语境。投英文期刊时，还要说明中国情境对一般问题意味着什么（黄炜；《经济学（季刊）》）。
- 几位作者都主张"先有想法再看文献"，但完全不看文献容易重复别人的工作，所以中间要有一轮探索性检索（陈强）。【判断】
