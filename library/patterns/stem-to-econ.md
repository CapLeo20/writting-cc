# 从理工科论文到经济学论文：写法差异

**一句话**：理工科论文围绕"方法和性能"组织，经济学论文围绕"一个经济学问题和可信的答案"组织。

## 结构上的差异

| | 理工科论文常见写法 | 经济学论文常见写法 |
| --- | --- | --- |
| 核心贡献 | 提出一种新方法、新材料、新算法，性能更好 | 回答一个经济学问题，答案可信（识别干净）且有经济含义 |
| 引言 | 背景 → 相关工作 → 本文方法 → 贡献列表 | 事实或张力 → 问题 → 识别 → **主要结果（带量级）** → 文献定位与贡献 |
| 引言里有没有结果 | 常常只预告"实验验证了有效性" | 必须有，而且要具体到数字（Evans：结果是引言里篇幅最大的部分） |
| "方法"的地位 | 主角 | 工具。识别策略要讲清"用的是什么变异、为什么可信" |
| 结果之后 | 消融实验、对比实验 | 稳健性检验（按威胁组织）、机制分析、异质性分析 |
| 结尾 | 总结 + 未来工作 | 结论 + 政策含义（中文期刊常要求成段的政策建议，如数技经要求不少于 1000 字） |
| 篇幅 | 较短，常有页数上限 | 较长，引言常有 10–15 段 |

## 思维上的差异

1. **"有效"不等于"有意义"**。理工科说"提升了 5%"就是贡献；经济学还要问"这 5% 相对什么、对谁、有多大福利含义"。
2. **相关不等于因果**。理工科实验可以控制变量；经济学多数是观察数据，必须单独论证识别。审稿人第一个问题往往是"内生性怎么处理"。
3. **读者想听故事**。理工科读者先看方法图和性能表；经济学读者先看问题是否重要、结论是否反直觉或能裁决争议。
4. **贡献要和具体文献对比**。不是"首次提出"，而是"相对张三（2020）用的 OLS，本文利用 X 政策的准实验……"。

## 用语上的差异

理工科习惯用语换成经济学通行说法，详见 [术语表](../../glossary/econ-fin-terms.md) 的"理工科易混用语"一节：

| 理工科习惯 | 经济学通行 |
| --- | --- |
| 鲁棒性 | 稳健性 |
| 实验组 | 处理组 |
| 仿真 | 模拟、数值模拟、反事实模拟 |
| 参数标定 | 校准（calibration） |
| 因变量 / 自变量 | 被解释变量 / 解释变量（中文期刊惯用） |
| 验证了方法的有效性 | 识别了 X 对 Y 的因果效应 |
| 显著提升 | 区分"统计显著"和"经济上可观" |
| 创新点 | 本文的贡献 |

## 可以保留的理工科习惯

- 逻辑清楚、术语一致、图表规范、可复现——这些在经济学同样受重视。数技经还会公开刊发数据和代码。
- Schimel 的《Writing Science》（OCAR 结构）是理工科读者熟悉的写作书，可以当作过渡：它讲的"故事结构"和 Keith Head 的引言五步法是一回事。
