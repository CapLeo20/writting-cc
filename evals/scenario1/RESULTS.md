# 场景一评测结果

只统计形式，不评判内容对错。每种条件每题只跑一次，样本小，数字只看大方向。重跑方法见 `run.sh` 开头的注释。

## 方法

- 题目：`prompts.tsv` 里的 6 道题，覆盖概念解释（q1）、结果解读（q4）、方法前沿（q5）、工具比较（q6）、操作步骤（q7）、一句话判断（q8）。
- 条件：base 不加规则；cc 用 Claude Code 输出风格；web 把网页版文字作为附加系统提示（在 Claude Code 里模拟，和真实网页版可能有差别）。
- 运行：`claude -p`，关闭所有工具，每题一个干净目录。
- 计数：`lint_reply.py`。"加粗行"指单独一行的加粗字，多半是在冒充标题；"结尾决定段"指以"需要你决定""下一步"开头的最后一段。

### 看到了什么

- **格式明显收敛，但没有一刀切**：列表、加粗减少七到八成；比较类问题（q6）仍然用表格，步骤类问题（q7）仍然用编号和代码块。这正是"格式按需"的意思。
- **段落变短**：最长段从 415 字降到 130–240 字，适合扫读。
- **加粗行冒充标题**：v0.1 一律禁止标题时出现过；v0.2 明确"用小标题，不用加粗行"后，cc 版降到 0。web 版仍有少量。
- **v0.2 的两个问题，v0.2.1 已修正**：6 个回答全部硬加"需要你决定"（降到 2 个，都是确实需要读者提供信息的题）；约 550 字的判断题也分了三个小标题（加了"不到约 600 字不用小标题"后，q8 改用段落）。
- **第一句都是结论**，常被整句加粗。这有助于快速抓重点，暂时保留。
- **长句没有明显减少**：超过 40 字的句子只少了约四分之一。抽象的句长规则作用有限，以后可以考虑在风格里加一段示范文字。
- **v0.2.1 出现一次"值得注意"**：之后在规则里加回了一句防套话。**这一句加上后还没有重测。**
