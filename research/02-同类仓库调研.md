# 调研报告二：有没有人做过类似的仓库

- 日期：2026-10-18
- 问题：有没有现成的"经济学写作经验与风格素材库"可以借鉴？

## 结论

没有找到和本仓库定位完全一样的项目，即**中文、面向经济学写作、以积累经验和审美为主、分三个场景**的素材库。但有几个项目各自做好了其中一块，值得借鉴，不必重复造：

| 需要的部分 | 已有的最好参考 | 本仓库怎么用 |
| --- | --- | --- |
| 英文经济学写作规则 | hanlulong/econ-writing-skill | 作为场景二 skill 的骨架；它的来源清单作为待收录清单 |
| 期刊投稿要求和核实方法 | brycewang-stanford/Awesome-Journal-Skills | 期刊卡片转引它已核实的事实；投稿格式不在本仓库重复维护 |
| 规则要注明出处、分清"有文献依据"和"经验观察" | yzhao062/agent-style | 对应本仓库的 `verified` 字段 |
| 从文字里归纳个人风格 | joshferrara/ghostwriter | 改造成 `library/STYLE-DIMENSIONS.md` 的观察维度 |
| 社区共建的写作经验合集 | MLNLP-World/Paper-Writing-Tips | 参考它"写前必看 / 终稿必查 / 百家之言"的组织方式 |

本仓库的定位是它们的空白处：**风格和审美**（怎么写才好），而不是投稿格式（怎么写才合规）；**中文**；**每条信息标明核实程度**。

## 逐个评价

以下仓库的 README 和部分文件我直接读过（GitHub 原始文件），评价是我的判断。

### 1. hanlulong/econ-writing-skill

- **是什么**：英文经济学论文写作 skill，综合 Cochrane、McCloskey、Shapiro、Head、Bellemare、Goldin 等 50 多份指南。四种模式：起草、改写、审阅、全文审计。来源清单按权威性分了四层（`sources/SOURCES_RANKED.md`，2026-02-16 更新）。
- **好在哪**：来源扎实；引言、摘要、结论都有"公式"；覆盖 13 种识别策略的写法。
- **不足**：按 AER 惯例写，比如要求文献综述并入引言，与中文期刊习惯冲突；主文件 739 行，超过官方建议的 500 行；没有中文语言规则。
- **借鉴**：场景二 skill 以它为骨架改写中文版；它的来源清单是本仓库 guides 的待收录清单（见 `library/guides/_to-collect.md`）。

### 2. brycewang-stanford/Awesome-Journal-Skills

- **是什么**：按期刊定制的投稿 skill 大合集。README 称共 4,166 个 SKILL.md、300 个包。和你的目标期刊相关的有：
  - 《经济研究》深度包（18 个 skill），附官方来源核查表；
  - 《数量经济技术经济研究》深度包（13 个 skill），附核查表和期刊档案；
  - 《经济学动态》《财经研究》各有一个轻量 profile；
  - **IREF 和 EAP 没有收录**。
- **好在哪**：核查表把每条事实分成"已联网核实（附来源和日期）"和"需复核"，不确定的数字不写死。还整理了"范文期刊归属避坑表"，比如几篇常被误认为《经济研究》的名篇实际发在《管理世界》《中国工业经济》。这种核实纪律值得照学。
- **不足**：体量太大；核实过的事实和模型写出的经验规则混在一起。比如《经济研究》的 er-style 规定"报告结果用过去时"，对中文意义不大。轻量 profile 里有通用模板话（如"高校学报型经济刊更重视……"套在《经济学动态》上）。
- **借鉴**：期刊卡片转引它已核实的事实并注明核查日期；范文候选优先用它核实过的篇目。投稿格式类信息不在本仓库重复维护，直接链接过去。

### 3. yzhao062/agent-style（The Elements of Agent Style）

- **是什么**：给 AI agent 生成英文技术文字用的 21 条规则（南加州大学一位计算机系教师维护）。12 条来自 Strunk & White、Orwell、Pinker、Gopen & Swan，每条注明出处章节；9 条来自作者对 LLM 输出的观察，明确标注"没有文献依据"。附有前后对比评测。
- **借鉴**：规则编号、逐条注出处、区分"文献依据"和"经验观察"。本仓库的 `verified`（原文 / 摘要 / 待核实 / 判断）是同一个思路。Gopen & Swan《The Science of Scientific Writing》（1990）是理工科读者熟悉的经典，已列入待收录清单。

### 4. joshferrara/ghostwriter

- **是什么**：从用户发出的邮件、消息里归纳个人写作风格，生成一份风格指南，按 17 个维度描述（语气、结构、句子、用词、不同场合、要避免的毛病等）。先保证"像本人"，再做去 AI 味清理。
- **借鉴**：维度化的风格描述。本仓库把它改造成学术写作版的观察维度（`library/STYLE-DIMENSIONS.md`），用来拆解学者、期刊和范文。你以后有了自己满意的经济学文字，也可以照这个思路生成一张"个人声音"卡片。

### 5. MLNLP-World/Paper-Writing-Tips

- **是什么**：中文社区共建的机器学习论文写作经验合集。分"写前必看"（常见错误配例子）、"终稿必查"、"百家之言"（收集各位老师公开的写作报告和文章），并整理成了一个 paper-writing skill。
- **借鉴**："百家之言"相当于本仓库的 guides；"写前必看 / 终稿必查"提示可以按写作阶段组织检查清单。它把有争议的建议标为"Attention"，也是标注可信度的一种做法。
- **不同**：面向英文顶会论文和 LaTeX 排版，不涉及经济学叙事。

### 6. 其他

- **hanlulong/awesome-ai-for-economists**：经济学家用 AI 的资源总表。"Agent Skills for Economists"一节还列了 Claes Bäckman 的 AI-research-feedback（多 agent 审稿报告）、Antonio Mele 的 awesome-econ-ai-stuff、Pedro Sant'Anna 的 claude-code-my-workflow（60 多个 skill 的学术工作流模板）、Scott Cunningham 的 MixtapeTools。这些偏研究流程，不是写作风格。
- **brycewang-stanford/Auto-Empirical-Research-Skills**：实证研究 skill 大目录（77 个合集、1,107 个 skill），见调研报告一。
- **antontarasenko/awesome-economics**：经济学资源链接合集，没有专门的写作部分。
- **blader/humanizer、op7418/Humanizer-zh、hardikpandya/stop-slop**：去 AI 味规则，已收录为 guide-humanizer-zh。

## 本仓库因此做的设计

1. **三层结构**（来源 → 素材 → 应用），收集和使用分开。
2. **卡片 + 元数据 + 自动索引**：一张卡片一个文件，元数据可被脚本校验，CI 检查索引是否最新。这是让仓库能长期维护的关键。
3. **核实程度必填**：吸取 Awesome-Journal-Skills 和 agent-style 的做法。
4. **投稿格式不重复维护**：期刊卡片只放风格观察和少量已核实的格式要点，详细投稿要求链接到 Awesome-Journal-Skills 和期刊官网。
5. **待收录清单**：`library/guides/_to-collect.md` 和 `library/papers/_candidates.md`，以后按清单逐步补。
